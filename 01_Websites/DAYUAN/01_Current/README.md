# Current Website

## Purpose

Preserve the current website source and reference materials before optimization begins.

## Store Here

- Current HTML, CSS, JavaScript, templates, and configuration files
- Existing visible copy, metadata, schema, forms, and navigation
- Tracking, consent, and verification code references
- Current screenshots, exports, crawl results, and URL inventories
- Source assets needed to reproduce the current page or website

## Rules

- Treat this directory as the baseline, not the optimization workspace.
- Do not overwrite the only copy of a source file.
- Preserve URLs, tracking, forms, integrations, and important content.
- Record the source URL and capture date for exported or downloaded files.
