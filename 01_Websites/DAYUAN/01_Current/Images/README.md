# Current Website Images

## Purpose

Store image assets collected from the current DAYUAN website for content inventory, visual review, optimization planning, and page reconstruction.

## Contents

- Product, application, manufacturing, quality, company, and case study images
- Logos, icons, diagrams, banners, and thumbnails
- Source URL, page usage, and capture date records where available

## Rules

- Retain original resolution and filename before creating optimized derivatives.
- Clearly identify stock images, renderings, diagrams, and real project photography.
- Do not expose confidential customer, equipment, drawing, or factory information.
