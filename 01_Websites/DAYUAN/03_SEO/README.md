# SEO

## Purpose

Store search strategy, keyword mapping, audits, implementation plans, and performance monitoring for the website project.

## Store Here

- SEO objectives, target markets, and baseline metrics
- Keyword research and search-intent classification
- Keyword-to-page mapping and topic-cluster plans
- Technical, on-page, internal-linking, and content audits
- Title, H1, Meta Description, canonical, schema, and indexation plans
- GSC exports, crawl reports, action lists, and validation records

## Rules

- Connect recommendations to qualified buyer traffic and inquiry value.
- State data source, date range, filters, and limitations.
- Separate observations, hypotheses, and approved implementation actions.
- Do not promise rankings, traffic, leads, or revenue.
