# Website Optimization

## Purpose

Store working and final optimized website files created from the preserved current version.

## Store Here

- Optimized HTML, CSS, JavaScript, templates, and components
- Page restructuring and UX improvements
- Conversion-path, CTA, form, accessibility, and responsive changes
- Before/after comparisons and implementation notes
- Validation results for links, forms, metadata, schema, tracking, and rendering

## Rules

- Analyze the existing structure and explain problems before modifying HTML.
- Create a dated backup and preserve the source version.
- Do not change URLs, remove tracking, or publish without approval.
- Keep working, review, and approved/final versions clearly identified.
