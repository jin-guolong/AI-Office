# Current JavaScript Archive

## Purpose

Store current website JavaScript files and dependency references required to understand page behavior, forms, navigation, analytics, and integrations.

## Contents

- Site-wide and page-specific JavaScript files
- Form, navigation, slider, tracking, and interaction scripts
- Dependency and version notes for external libraries

## Rules

- Preserve analytics, tag management, conversion, CRM, and form-related code.
- Do not execute unverified scripts or store credentials and API secrets.
- Modify copies under `02_Optimize`; retain these files as the current-state baseline.
