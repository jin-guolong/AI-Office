# Current Website Snapshot

## Purpose

Store dated snapshots that document the current website condition before optimization work begins.

## Contents

- Desktop and mobile screenshots
- Crawl exports, URL inventories, navigation maps, and page lists
- Archived page packages or other reproducible website captures
- Snapshot notes including website URL, capture date, device, viewport, and tool

## Rules

- Create dated snapshot sets and keep them read-only as project baselines.
- Capture key page types, navigation, forms, downloads, and visible error states.
- Do not treat a snapshot as proof of live behavior when scripts or external resources were unavailable.
