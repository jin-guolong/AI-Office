# Images and Media

## Purpose

Store approved visual assets used in the industrial B2B website and its content production workflow.

## Store Here

- Product, factory, process, quality, Application, and Case Study images
- Diagrams, technical drawings, charts, icons, and approved illustrations
- Video files, thumbnails, captions, and transcripts
- Original, working, optimized, and web-ready asset versions
- Media-source, ownership, approval, caption, and alternative-text records

## Rules

- Do not present stock, representative, rendered, or AI-generated media as real evidence.
- Protect confidential customer, drawing, screen, document, and personal information.
- Use descriptive file names and retain approved originals.
- Optimize dimensions, format, and file size without losing required technical detail.
