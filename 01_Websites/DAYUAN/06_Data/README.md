# Data

## Purpose

Store raw, cleaned, and analyzed data used to evaluate website, SEO, content, and conversion performance.

## Store Here

- GA4, GSC, CRM, ranking, crawl, and website exports
- Keyword, URL, landing-page, conversion, and content inventories
- Cleaned datasets, mappings, calculations, and analysis workbooks
- Data dictionaries, metric definitions, filters, and methodology notes
- Charts or tables used as sources for reports

## Rules

- Keep raw exports separate from cleaned and analyzed data.
- Record property, date range, timezone, filters, and export date.
- Do not treat clicks as sessions, users as leads, or submissions as qualified inquiries.
- Protect personal, customer, commercial, and confidential project data.
