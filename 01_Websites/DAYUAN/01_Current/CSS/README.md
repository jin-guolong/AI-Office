# Current CSS Archive

## Purpose

Store the current website stylesheets and related style assets as a reference for layout, branding, responsive behavior, and future HTML optimization.

## Contents

- Site-wide and page-specific CSS files
- Framework, theme, and component stylesheets
- Notes identifying the source URL, theme version, or capture date

## Rules

- Keep original filenames where practical to preserve dependency references.
- Do not edit archived styles directly; create working versions under `02_Optimize`.
- Record external or third-party stylesheet dependencies when they are not stored locally.
