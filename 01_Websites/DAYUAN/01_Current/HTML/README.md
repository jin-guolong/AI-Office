# Current HTML Archive

## Purpose

Store the current website HTML files and page-source exports used as the baseline for DAYUAN website analysis and optimization.

## Contents

- Homepage, category, product, solution, application, blog, and case study HTML files
- Reusable HTML partials or templates obtained from the current website
- Page-source exports with the source URL and capture date recorded

## Rules

- Preserve the original files and do not overwrite the only current-site copy.
- Do not remove tracking code, forms, structured data, canonical tags, or internal links from archived files.
- Place modified HTML in `02_Optimize`, not in this directory.
